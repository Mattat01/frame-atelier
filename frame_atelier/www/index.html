Getting started

  • Settings → TV Connection: enter the TV's IP (or press Scan). A static IP in your router is recommended.
  • Settings → Unsplash API: paste a free Access Key from unsplash.com/developers.
  • If the TV shows an “Allow connection?” prompt the first time art is sent, accept it. The pairing token is then saved.

Library tab

Everything stored in the TV's My Photos art collection.

  • Current image is shown enlarged at the top (green border) and marked Current in the grid — it follows the slideshow automatically.
  • Set as current (hover an image): shows it now if Art Mode is on, or queues it for next Art Mode if you're watching TV — it never interrupts viewing.
  • Select & delete: tap to multi-select; delete selected / all to free the TV's art memory.
  • Matte (per image, change any time): pick a style + colour → Apply to current / selected. none = full screen. The hero shows a live colour preview.
  • Filter (per image): a photo treatment (None / Aqua / ArtDeco / Ink / Wash / Pastel / Feuve) → Apply.

Upload tab

  • Search Unsplash (the × clears the box). Results load as you scroll — no paging.
  • Favourites: tap the ☆ star to save the current search (★ = saved, tap to remove). Saved searches show as chips (15 per page, use ‹ › for more). Manage them under Settings → Favourite searches. Long terms are shortened with “…” (hover to see the full text).
  • Multi-select: tap results to select; selection persists across searches.
  • A floating bar appears with a thumbnail strip — tap one to choose which displays immediately. Toggle Show one now off to just add to the library.
  • Send to TV uploads each image full-screen (cropped to 4K) with a progress count. Keep the tab open until it finishes.

Settings tab

  • Favourite searches: add/remove terms for the Upload chips.
  • Slideshow: auto-rotate on/off, interval, Shuffle.
  • Brightness & Colour temperature: live, global Art-Mode settings.
  • Show matte controls: hide the Library matte row if you don't use mattes.
  • Debug mode: logs every TV action to the add-on Log. Probe TV art settings: logs your TV's real options.
  • Press Apply to save the slideshow settings.

How the slideshow behaves

SituationBehaviour
Watching a live channelTicks are skipped — it won't pull you to art.
Set an image (this app) while watchingQueued silently for next Art Mode.
Change image with this appSlideshow keeps running.
Change image on the TV remoteSlideshow pauses & unticks itself.

Good to know

  • A matte crops the photo edges — there's no zoom/scale-to-fit on the TV. Use none for the full image.
  • Mattes & filters are per image and changeable live (no re-upload). Brightness & colour temperature are global.
  • The TV must be awake/reachable. Only Unsplash calls leave your network. Per Unsplash's guidelines, each search result shows the photographer's name & a link to their profile and registers the required download — note the TV itself doesn't display a credit.
Something not working on your TV? Turn on Debug mode in Settings and check the add-on Log tab — it records every action and its result.
